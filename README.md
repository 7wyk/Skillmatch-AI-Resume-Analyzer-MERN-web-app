# SkillMatch AI

> An AI-powered SaaS platform that analyzes resumes and provides instant feedback on ATS compatibility, keyword optimization, and grammar quality.

## ✨ Features

- **Resume Analysis**: Upload resumes and get instant AI-powered feedback
- **ATS Score**: Check compatibility with Applicant Tracking Systems
- **Keyword Matching**: Identify missing industry-specific keywords
- **Grammar Check**: Detect and highlight grammar issues
- **Dashboard**: Track resume performance with visual analytics
- **Modern UI**: Futuristic fintech design with smooth animations

## 🚀 Getting Started

### Installation

```bash
# Install frontend dependencies
cd client
npm install

# Install backend dependencies
cd server
npm install
```

### Running the App

```bash
# Terminal 1 - Start frontend (http://localhost:5173)
cd client
npm run dev

# Terminal 2 - Start backend (http://localhost:5000)
cd server
npm run dev
```
